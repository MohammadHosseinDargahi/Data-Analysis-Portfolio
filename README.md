# Data Analysis Portfolio

Welcome to my data analysis portfolio. This repository showcases practical projects in data analysis, data cleaning, reporting, and workflow automation using Microsoft Excel and Google Sheets.

## Excel Projects

1. **[01. Medical Cost Data Analysis](./Excel/01-Medical-Cost-Analysis)**
   - Analysis of medical insurance charges based on regional grouping, BMI categories, and smoking status.
   - Includes summary reports and pivot table breakdowns.

2. **[02. Excel Data Cleaning](./Excel/02-Excel-Data-Cleaning)**
   - End-to-end data cleaning, text manipulation, and formatting using standard Excel formulas.
   - Extracts keys, cleans phone numbers, handles dates, and standardizes addresses.

3. **[03. Global Economic Analysis](./Excel/03-Global-Economic-Analysis)**
   - Advanced Excel data analysis using `XLOOKUP`, dynamic array functions (`FILTER`, `SORT`), and GDP ranking.
   - Interactive country lookup, proximity analysis, and filtered indicator reports.

## Google Sheets Projects

### [Study Challenge Tracker](./Google-Sheets/Study-Challenge-Tracker)
- A Google Sheets and Google Apps Script system designed to support a 40-day study challenge for 50 participants.
- Includes participant profiles, daily study tracking, and a performance dashboard.
- Features a web app for submitting daily study reports and using recovery tokens.
- Includes source code, screenshots, and links to the demonstration spreadsheet and web app.
